# Escopo Global x Escopo local 
>global:
- Pode ser acessada por qualquer parte do sistema. No entanto, em Pyhton ela escaapa. O valor da variavel global é modificado em alguma estrutura e o valor fica sendo o último usado nessa estrutura
>Local: 
- Ela é criada dentro de uma estrutura. Ela vale somente naquela estrutura e se em um outro nivel ela ser utilizada, ela escapa porém pode ser reutilizada.

# Funções [def]
 -> é um objeto guardado numa variavel, que contem um bloco de codigo ainda não executado.
 Quando você a chama, o python cria um espaço de nomes novos e temporários. 
 [def] -> Palavra chave que inicia a declaração da função.
 [nome_funcao] -> Indentificador  - utilizando o padrão ""snake_case"".
 [parametro] -> Dados de entrada entre parenteses.
 [argumento] -> Valores que ocupam o lugar dos parâmetros.
 [docstring] -> Documentação entre aspas duplas.
 [corpo] -> Bloco identado contendo a lógica da função.
 [return] -> Valor retornado, se adef não tiver o return, o padrão é null
